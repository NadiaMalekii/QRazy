**QR Code Generator & Reader**

A full-stack application that lets you generate QR codes and scan/decode them from images.  
Built with **ASP.NET Core** on the backend and **React** on the frontend.

---

## Features

- **Generate QR codes** from any text or data
- **Scan / decode** QR codes from uploaded images (base64)
- Download generated QR codes as PNG
- Simple and clean REST API with Swagger documentation
- Modern React frontend

---

## Tech Stack

| Layer       | Technology                          |
|-------------|-------------------------------------|
| Backend     | ASP.NET Core (.NET 10)              |
| QR Generate | QRCoder                             |
| QR Decode   | ZXing.Net                           |
| Frontend    | React 19 (Create React App)         |
| API Docs    | Swagger / OpenAPI                   |
